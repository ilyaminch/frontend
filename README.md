# ГИС-помощник — frontend

React, TypeScript, Vite, Leaflet, обычный CSS. Пакетный менеджер — npm;
точные зависимости закреплены в package-lock.json. Node.js: 24.18.0 при подготовке.

## Локальный запуск

```powershell
npm ci
npm run dev
```

Откройте http://localhost:5173. В браузере используйте именно localhost.
`.env.development` и `.env.production` включают `VITE_DATA_MODE=api`.
Frontend использует настоящий backend: при загрузке проверяет `/auth/me`,
после входа получает реестр, выбранный слой и создаёт отдельный диалог вкладки.
Учётные записи выдаёт владелец стенда; реальные пароли не входят в этот репозиторий.
HttpOnly-cookie сохраняет вход при refresh; история и dialogue_id не сохраняются.

Для явного режима примеров задайте `VITE_DATA_MODE=fixtures` в
`.env.development.local` и перезапустите dev-сервер. Вход в примеры — demo / demo.
В этом режиме есть постоянная метка «Примеры данных · без API» и меню состояний;
запросы к backend не выполняются. Геометрии и атрибуты fixtures иллюстративные,
не являются принятым демонабором. При ошибке API автоматического перехода
в примеры нет. Неизвестное значение VITE_DATA_MODE показывает ошибку настройки.

## Подключение API

Согласованный профиль: frontend http://localhost:5173, backend
http://127.0.0.1:8000, backend PUBLIC_ORIGIN=http://localhost:5173,
COOKIE_SECURE=false только для локального HTTP. Backend настраивает его владелец.
Vite уже проксирует `/api` с сохранением пути и исходного Origin; target
настраивается серверной переменной BACKEND_PROXY_TARGET. Браузер использует
относительные `/api/v1/...`. Для собранной версии веб-сервер также должен
проксировать `/api` на тот же backend. Тайм-аут proxy — 330 секунд, клиента
чата — 320 секунд при серверных 300. POST автоматически не повторяются.

API-адаптер передаёт credentials и CSRF из login/me, очищает защищённое состояние
при 401 и по expires_at. 403 показывается без обхода прав. При неподтверждённом
выходе предлагает повторить действие вручную. Никакие пароли и токены
не записываются в localStorage/sessionStorage.
Типы сверены с OpenAPI запущенного стенда; bigint и версии — строки.
Карточка использует версию показанного результата. Отмены и поколения запросов
не позволяют поздним ответам заменить более новое состояние.

Чат показывает серверное сообщение, код ошибки и request_id; при уточнении,
unsupported и ошибке карта сохраняется. Результат заменяет объекты согласованно
с сообщением. Нулевой результат очищает выборку без перемещения viewport.
«Новый диалог» очищает историю, инвалидирует поздние ответы, удаляет прежнюю
сессию и создаёт новую. Ручное переключение слоёв защищено от позднего результата чата.
Переключатели независимы: можно одновременно показать несколько слоёв или выключить
все. Карта и список объединяют включённые слои одной версии данных; при несовпадении
версий предлагают обновление. Районы рисуются под точками и линиями. Карточки
различают ID районов и объектов. «Обновить слои» перечитывает включённые слои.
Успешный новый результат чата заменяет выборку согласно map_action=replace API;
после него другие слои можно снова добавить переключателями.
Карточки вызываются через /objects или /regions с dataset_version карты.

## Реестр и импорт

Реестр доступен обеим ролям: `#/admin/layers`. Администратор после входа
попадает в него; пользователь — на карту. Переход обратно доступен в интерфейсе.
Реестр показывает шесть слоёв, фактические количества, геометрии, дату обновления
и общую версию данных. Административные действия доступны только admin.

`#/admin/import` принимает один GeoJSON/JSON для полной замены выбранного слоя.
Лимит загружается из `/query-capabilities` (на проверенном стенде — 20 MiB).
Браузер проверяет размер, JSON/FeatureCollection, поддерживаемый тип геометрии
и строковые уникальные ID. Атрибуты, топологию и конфликты проверяет сервер
при единственном multipart POST с исходным файлом; отдельной серверной проверки
без записи в текущем API нет. Перед отправкой требуется подтвердить замену.

Импорт и восстановление демонабора не повторяются автоматически. При неизвестном
исходе показывается предупреждение и перечитывается версия реестра.
Восстановление требует отдельного подтверждения. После операции данные карты
сбрасываются, интерфейс предлагает повторить поиск; реестр перечитывается.
Ошибка содержит безопасное сообщение, код, request_id и пути ошибок атрибутов.

Состояние стенда зависит от работы backend-разработчика. На 22.10.2026 подключена
модель и загружен малый проверочный набор 28 объектов + 4 района; это не полный
демонабор 500 + 4. Пустые данные и LLM_UNAVAILABLE также обрабатываются интерфейсом.

## Карта и ассеты

VITE_TILE_URL задаёт URL тайлов; по умолчанию
https://tile.openstreetmap.org/{z}/{x}/{y}.png. Видимая атрибуция ведёт на
https://www.openstreetmap.org/copyright. Используется обычное браузерное кеширование;
предзагрузка и offline-скачивание отсутствуют. Политика источника:
https://operations.osmfoundation.org/policies/tiles/.

UI-иконки и фон входа в public/assets экспортированы из предоставленной Figma:
https://www.figma.com/design/PfCMjUTc1RsLKBo8uIoC5G/Untitled.
Схематическая карта макета не используется вместо рабочей карты.
Шрифт Inter поставляется локально через @fontsource/inter; лицензия OFL
находится в установленном пакете. Зависимости и их лицензии остаются у владельцев.
